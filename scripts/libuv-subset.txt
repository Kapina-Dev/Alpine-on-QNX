# libuv event-loop subset for scripts/run-libuv-smoke.sh (Phase 3 part 4
# gate). One test name per line from libuv 1.52.1's test/test-list.h;
# "#" starts a comment. Only the user removes a test from this list.
#
# Left out by construction: IPv6 (tcp6_*, *bind6*, *connect6*), TTY
# (tty_*), DNS (getaddrinfo, getnameinfo, threadpool_cancel_getaddrinfo,
# threadpool_cancel_getnameinfo), /proc readers (uv_resident_set_memory,
# get_memory, uptime, cpu info) and process-title tests. Also left out:
# addresses other than 127.0.0.1 (tcp_close_while_connecting and the
# connect-timeout tests dial unroutable hosts, and the device has no
# network) and Linux abstract-namespace pipes (pipe_getsockname_abstract,
# pipe_getsockname_autobind), which are not a path under /tmp.
